# User guide

How to install better-smc-mixer on an M-Vave SMC-Mixer, connect it, set it up and play it. What
the project is: [about.md](../about.md).

The editor runs in the browser at [https://doctorsolberg.github.io/better-smc-mixer/editor/](https://doctorsolberg.github.io/better-smc-mixer/editor/), with the firmware published
beside it. Each version's notes are on [GitHub Releases](https://github.com/doctorsolberg/better-smc-mixer/releases).

| Page | What it covers |
|---|---|
| [install.md](install.md) | installing over USB or Bluetooth, updating, and going back to M-Vave's firmware |
| [connecting.md](connecting.md) | USB, Bluetooth MIDI with a Mac, an iPhone or iPad, and M-Vave's wireless DIN adapter |
| [editor.md](editor.md) | the editor: Connect, Linked and Separate, Send and Save, Map instrument, Learn, files, support reports |
| [first-preset.md](first-preset.md) | a first setup, step by step: a fader, an encoder and a note button for a synth or an app |
| [panel.md](panel.md) | presets and pages, Shift, faders, encoders, buttons, the BT button and the factory layout |

New to better-smc-mixer? Start with [install.md](install.md), then [first-preset.md](first-preset.md).
